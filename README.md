# Blinkit-Grocery-Anaysis
Analysed Blinkit Grocery sales by using Power BI, SQL, Python

Conducted end-to-end data analysis on 8,523 retail records Cleaned and transformed data using SQL (handling nulls, standardization) Developed KPI-based analysis (Sales, Ratings, Item Count) Built interactive dashboard in Power BI with filters and visual insights Identified top-performing categories and outlet segments
